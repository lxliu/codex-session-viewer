## 6GiB 实体文件

运行：`python3 src/tools/run_perf.py`。该工具编译 Go 测试程序，生成并实际写入文件，测试后自动清理，不使用稀疏文件冒充实际扫描。

样本：约 6,442,478,100 字节，98,397 行；主体为约 64KB 的工具输出，时间戳存在重复与回退。这是应用缓存首次建立的测试，操作系统页缓存可能命中，不是冷磁盘读取基准。

| 指标 | 实测 |
| --- | --- |
| 最新尾部内容接口 | 7.33ms |
| 首次全量索引（包含初次尾部读取） | 13.88 秒 |
| 新 Store 复用已落盘索引 | 0.33ms |
| 索引后原始范围读取 | 0.18ms |
| 可视化最新范围 | 2.94ms |
| 可视化向前连续加载 | 2.75ms |
| 日期定位（乱序，扫描紧凑索引） | 28.86ms |
| 测试进程峰值 RSS（`wait4` 测量） | 69.8MiB |
| GC 后 Go runtime `Sys` | 约 70.3MiB |

本轮性能复测与六平台交叉编译同时运行，存在 CPU / 磁盘竞争；上一轮单独运行首次索引约 8.90 秒、峰值 RSS 22.0MiB。表格记录最新一轮结果。

RSS 是 Go 测试进程的测量值，不包含浏览器和操作系统可回收的文件缓存。内存测试以 2GiB 为失败阈值；本次实测远低于 2GB。数据结构复杂度、记录大小、磁盘速度和同时打开的界面会影响结果，不能将一份合成样本的结果外推为所有 6GB 文件都具有相同耗时。
